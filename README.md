# Sistema de Seguimiento de Donaciones - Cáritas Formosa

## Trabajo Práctico N.º 2

**Alumno:** Carlos Daniel Cuevas  
**Proyecto:** Sistema de seguimiento de donaciones para Cáritas Formosa

## Descripción

Este proyecto tiene como objetivo desarrollar un sistema para gestionar y realizar el seguimiento de las donaciones recibidas y entregadas por Cáritas Formosa.

El sistema permite registrar beneficiarios, donaciones, entregas y solicitudes, facilitando el control y seguimiento de los recursos disponibles.

## Contenido del repositorio

- `src/`: Código fuente desarrollado en Java.
- `dao/`: Clases encargadas del acceso a datos.
- `modelo/`: Clases correspondientes al modelo del sistema.
- `util/ConexionBD.java`: Conexión con la base de datos.
- `Main.java`: Clase principal de la aplicación.
- `caritas_donaciones_final.sql`: Script MySQL para la creación de la base de datos.

## Tecnologías utilizadas

- Java
- MySQL
- JDBC
- GitHub
